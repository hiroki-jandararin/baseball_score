# Review Domain LLM Knowledge（MVP）

## 前提戦略

- AIは試合終了後に1回のみ実行（1試合＝1リクエスト）
- ルールで処理可能な部分はAIを使わない
- 出力はInstagramでシェア可能な形式を前提とする

## ドメイン責務

- reviewは試合後のコンテンツ生成のみ担当
- DB・HTTP・認証は扱わない
- 入力（事実）と出力（表現）を分離する

## 非AI領域（必須実装）

- MVP算出（スコアリング＋同点優先順位）
- 称号付与
- 簡易評価スコア
  → 安定した構造データを生成する

## AI利用領域（固定）

- チーム新聞（headline・summary）
- MVP理由コメント
- 各選手コメント

## AI入出力仕様

入力JSON：
{
"match": {...},
"mvp": {...},
"players": [...]
}

出力JSON（厳守）：
{
"headline": "...",
"summary": "...",
"mvp_comment": "...",
"player_comments": [
{"player": "A", "comment": "..."}
]
}

## トーンルール

- ポジティブ・ネタ寄り
- 悪意・批判・不快表現は禁止
- チームで盛り上がる内容を優先

## TDD原則

- テストファーストで進める
- pure functionを優先
- 変更しやすいルールはserviceに分離

## ゴール

- AIなしでも成立する構造を作る
- AIで「見返したくなる試合コンテンツ」に昇華する
- 1画面で完結し、そのままSNS共有できる体験を作る
